# EPIC OS Installation Flow

## Welcome
EPIC OS Setup
- Install EPIC OS
- Try EPIC OS without installing
- Repair/recovery

## Installation
- Language
- Keyboard
- Network
- Disk selection
- Automatic partitioning or advanced partitioning
- Optional encryption
- Time zone
- User account
- Review

## Boot
For UEFI systems:
- EFI System Partition
- Linux root partition
- Optional swap
- Install a UEFI boot entry

## First boot
- Welcome screen
- User login
- Network
- Updates
- Driver setup
- Gaming setup
- Android environment setup

Never automatically erase a disk without an explicit confirmation showing the exact disk and its size.
